Descubre por qué aparece HTTP 401

Comprueba si la aplicación pública puede llegar a sus módulos. No solicita credenciales, no entra en tus cuentas y no necesita claves de la bóveda privada.

Comprobación de la versión publicada

La página puede cargar aunque las API estén bloqueadas. Una verificación con x-waeweb-api: 1 distingue las respuestas del backend de un 401 generado antes de llegar a él.

Las pruebas de red solo se ejecutan al pulsar el botón.

Qué significa cada resultado

HTTP 401 sin marca WAEWEB

La solicitud probablemente se detuvo antes de llegar al backend. Comprueba el acceso del despliegue, el dominio público y que /api/* llegue a las funciones de WAEWEB.

API disponible, módulo bloqueado

El backend responde, pero la capacidad puede estar desactivada. Rutas y direcciones precisas necesitan la configuración del proveedor; Índice WAE es privado y requiere autorización aparte.

Mapas sin cartografía

El mapa incrustado depende de OpenStreetMap: si un tercero rechaza o impide la vista, no se puede forzar desde WAEWEB. El enlace al mapa original sigue disponible.

Versión anterior

Si la versión es anterior al código de GitHub, primero hay que confirmar la rama de producción y el despliegue. Un commit en un PR en borrador no actualiza necesariamente tu dominio.
